# Rajasthan Royals IPL Auction Data Analysis

### Data-Driven Player Scouting Through Pressure Performance Analytics

## Overview

This project analyses IPL ball-by-ball data from 2022 to 2026 to identify players who perform effectively under high-pressure match situations.

The objective is to support Rajasthan Royals' IPL 2027 auction scouting through data-driven evaluation of batting and bowling performance.

## Project Objectives

- Analyse player performance using ball-by-ball IPL data.
- Identify high-pressure batting and bowling situations.
- Evaluate player performance across different pressure scenarios.
- Develop comparative scouting rankings.
- Support evidence-based auction decisions.

## Dataset

The project uses historical IPL datasets, including:

- Ball-by-ball delivery records
- Match information
- Competition details
- Team and player mappings
- Playing XI information

**Coverage:** IPL 2022–2026  
**Deliveries analysed:** 87,673  
**Matches analysed:** 367

## Methodology

1. Data cleaning and preparation.
2. Delivery-level pressure identification.
3. Batting and bowling performance evaluation.
4. Player eligibility filtering based on minimum sample requirements.
5. Scoring under permissive, base and strict pressure scenarios.
6. Consensus ranking using mean rank and rank dispersion.

## Key Performance Indicators

### Batting
- Pressure strike rate
- Pressure batting average
- Strike-rate uplift
- Boundary rate
- Sample confidence

### Bowling
- Pressure economy
- Wickets per over
- Dot-ball percentage
- Economy improvement
- Sample confidence

## Limitations

The rankings represent historical performance, not guaranteed future performance or auction availability. Auction registration, player fitness, reserve prices and squad requirements must be independently verified.
